# YANIBOX Киноклуб

Витрина фильмов, очередь заказов за баллы и панель стримера. Оценку от 0 до 10 выставляет стример. Код и опубликованный список фильмов хранятся в одном репозитории GitHub.

## Сайт

В настройках репозитория открой **Settings → Pages → Deploy from a branch** и выбери **main** и **/(root)**. Витрина открывается по адресу GitHub Pages, панель стримера находится по адресу `admin.html` внутри сайта.

Локальная проверка из папки проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открой `http://localhost:8765/` или `http://localhost:8765/admin.html`.

## Фильмы и публикация

1. Добавь фильм в панели. Можно указать зрителя, категорию, статус, оценку, постер и заметку.
2. Проверь поле с репозиторием. Для сайта на `github.io` панель заполняет его сама.
3. Создай [fine-grained token](https://github.com/settings/personal-access-tokens/new) с доступом только к репозиторию сайта и правом **Contents: Read and write**. Вставь его в поле панели. Поле очищается при перезагрузке вкладки.
4. Нажми **Опубликовать**. Панель сохранит список коммитом. Витрина покажет обновление после публикации GitHub Pages.

Черновик хранится в браузере. Если список уже меняли в другом браузере, панель предупредит о конфликте и сохранит черновик. Кнопка **Загрузить с GitHub** подгружает актуальную версию. При наличии черновика панель спросит, можно ли его заменить. Фильмы, ники, заметки и оценки из опубликованной версии видны посетителям.

## Заказы за баллы Twitch

1. В [консоли Twitch](https://dev.twitch.tv/console/apps) зарегистрируй приложение. Впиши адрес возврата, который показывает панель рядом с кнопкой **Копировать**.
2. В настройках баллов канала создай награду «Заказать фильм» и включи обязательный ввод текста.
3. Вставь **Client ID** в панель, войди под аккаунтом владельца канала и выбери награду. Статус **Слушает награду** подтверждает подписку.
4. Оставь панель открытой на время стрима. Зритель активирует награду и вводит название. Фильм сразу попадает в черновик, а если включена автоматическая публикация и введён токен GitHub, панель сама опубликует очередь.

Одна активация добавляется один раз. При обрыве связи панель переподключается, но Twitch не воспроизводит пропущенные события. Если заказ пропущен, его можно перенести вручную из очереди наград Twitch. Статусы фильмов меняются в киноклубе, а выполнение и возврат баллов ведутся в Twitch.
